PII Redaction Tool

Scaler AI Labs Assignment

A professional, production-grade hybrid solution utilizing precision heuristics, validation algorithms, and deterministic pseudonymization to safeguard Word (.docx) documents.

1. About the Project

This tool reads a Word document (such as a Red Herring Prospectus) containing complex tables, runs, and paragraphs, and outputs a format-preserved redacted version. It replaces all sensitive data with realistic, contextually consistent fake replacements using a seeded mapping engine.

2. Categories Detected

Ensures compliance and coverage for 9 essential classes of sensitive data:

Full Names Email Addresses Phone Numbers Company Names Mailing Addresses SSNs Credit Cards Dates of Birth IP Addresses

3. Detection Approach

We leverage a multi-layered rule-based architecture to guarantee high precision:

  • Structured validation using standard checksums (Luhn check for credit cards) and range boundary checking (IPv4 octets).
  • Contextual indicators (Registered/Corporate office tags for addresses, birth indicators for DOB).
  • Title and proximity matching rules for names and companies.
  • Iterative single-replacement run loops to maintain style/font.
